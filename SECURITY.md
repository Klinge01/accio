# Security

Accio reads your local files and sends excerpts of them to a cloud model. If you find a way
it leaks more than the README's "What leaves your Mac" table says, or any other
vulnerability, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/Klinge01/accio/security/advisories/new),
not in a public issue.

Please include what you ran, what you expected to stay local, and what left the machine.
